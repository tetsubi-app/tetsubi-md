DEKIRU Sans

A modified version of IBM Plex Sans 3.005 (Copyright 2017-2018 IBM Corp.,
SIL Open Font License 1.1, https://github.com/IBM/plex).

Changes: line metrics only. Ascender 951, descender -242, line gap 0
(was 1025 / -275 / 0 in hhea), so lines are as tall as the iOS system
font's (1.193 em instead of 1.300 em). Glyphs are unchanged.

"Plex" is a Reserved Font Name under the license, so the modified fonts
are named DEKIRU Sans. The license is in DekiruSans-LICENSE.txt.
